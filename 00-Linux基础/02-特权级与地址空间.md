# 特权级与地址空间

两个**正交**的维度，不要焊在一起。

![[特权级与地址空间.svg]]

## 维度一：特权级（CPU 的「身份」）

- 记在 CS 寄存器低 2 位，叫 CPL（见 [[术语表]]）。
- `3` = ring3 用户态，`0` = ring0 内核态。
- 决定「你够不够格执行**特权指令**、碰**高权限内存**」。

特权指令举例：`cli`（关中断）、`lgdt`、`in/out`、`mov cr3`。它们改的是**系统全局状态**，绝不能给用户态。

## 维度二：地址空间（内存的「墙」）

- 由页表 + MMU 实现，是「虚拟地址 → 物理地址」的翻译表。
- 每个进程一套页表，所以天然隔离；每页带 U/S 位（`0` = 仅内核，`1` = 用户可访问）。

## 汇合点

内存访问那一瞬间，MMU 拿 **CPL** 去比页表项的 **U/S 位**：
用户（CPL=3）访问内核页（U/S=0）→ 拒绝，抛异常。

所以「内核态 / 用户态」的本质是**特权级**，不是「地址隔离」。

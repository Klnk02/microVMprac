# 第二轮教学契约与评估标准

生效日期：2026-11-17。用户已确认本标准。关联：[教学约定](../AGENTS.md)、[课程计划](00-学习计划.md)、[学习记录](学习记录.md)、[面试题库](面试题库.md)。本文是第二轮执行与验收的统一依据；历史笔记保留，冲突时按用户最新要求与本文执行。

## 1. 最终目标与课程顺序

面对一条沙箱操作链路，能独立解释它如何工作、预测条件变化后的行为；面对异常，能提出可区分的原因，选择证据缩小范围，并明确结论的边界。

- 根本目标是深入理解原理并形成初步独立分析能力；面试用于选择重点与练习表达。
- 第二轮从第1课开始，按原课程顺序复习。五个必深点决定深入程度，不替代课序；网络/envd与创建启动是明确的补强项。
- 课程进度、材料数量、代码阅读行数和“当时听懂”只表示投入或覆盖，不计作能力得分。
- 本标准是本轮教学目标，不是行业认证，也不据一次高分宣布具备生产排障或带人能力。

## 2. 七个知识领域：不能以强项抵消空白

| 领域 | 必须能独立完成的任务 |
|---|---|
| 执行与虚拟化 | 解释物理CPU、vCPU线程、Guest调度关系；画出KVM_RUN与退出处理分流 |
| 内存与地址空间 | 画清GVA/GPA/HVA/HPA、memslot与EPT；解释跨进程读取、缺页和COW |
| 存储与设备IO | 从Guest文件读取追到后端再返回；区分VirtIO、ublk、io_uring、OverlayBD及各自完成点 |
| 创建、快照与恢复 | 追踪创建、就绪、暂停、捕获、持久化与恢复；指出一致性和外部状态边界 |
| 网络与envd通信 | 追踪Host到Guest应用的请求及返回；区分网络连通、监听、健康、鉴权和命令结果 |
| 隔离与资源生命周期 | 说明虚拟化、namespace、cgroup、seccomp、降权各约束谁；判断何时可安全释放资源 |
| 性能与并发 | 定义wall、CPU、吞吐与尾延迟；分析缓存、排队、阻塞、忙轮询和优化代价 |

七域都须评估并保留证据。某域存在关键因果缺口时单列补强，不用其他域高分覆盖。未评估写“待评估”，不自动给0分。

## 3. 五项能力：各占20%

| 能力 | 可观察表现 | 评估方法 |
|---|---|---|
| 机制理解 | 能解释因果、成立条件及代价 | 闭卷画图；解释为什么、少一步会怎样 |
| 链路与实现追踪 | 能落实到进程、线程、接口、参数与返回值 | 追关键调用链，标地址归属、数据位置和完成条件 |
| 验证与证据判断 | 能预测、选证据并解释其证明范围 | 源码或实验；说明支持什么、尚不能证明什么 |
| 问题提出与定位 | 能提出具体问题和可区分解释，逐步缩小范围 | 陌生故障与设计审视；按观测修正判断 |
| 迁移与保持 | 换条件、隔一段时间仍能推理 | 改缓存、线程数、故障位置或恢复方式；延迟重建 |

### 统一0—4分尺度

| 分数 | 判定 |
|---|---|
| 0 | 尚未形成解释，或核心结论错误且无法修正 |
| 1 | 能认出术语和组件，因果关系不清楚 |
| 2 | 在提示下可完成主要推理，仍有关键遗漏 |
| 3 | 能独立解释或验证，结论与证据匹配，并说明主要边界 |
| 4 | 换条件仍能推理，识别反例、比较替代解释并主动修正模型 |

3分是主要目标。评分对应具体任务表现，记录是否提示、允许何种查阅及证据类型。教师讲解后的复述不能冒充未提示的独立回答。

如需100分展示：五项均有足够评估证据后，按各项0—4分的综合判定计算，总分=5×五项分数之和。未评估项不补零、不计算完整总分。总分仅辅助展示，不能替代七域覆盖与逐项能力判断；单次案例得分不直接成为最终分。

## 4. 故障分析的五个检查项

1. **问题具体**：明确预期、实际、发生范围与已知条件。
2. **解释可区分**：至少提出两个具体候选原因，并预测它们产生的不同现象。
3. **观测有效**：所选观测能区分候选原因，不只是重复收集同类信息。
4. **结论克制**：证据不足时保留候选原因，不强行宣布根因。
5. **后续合理**：结果到来后更新模型，选择下一条观测或最小验证。

猜中原因不直接算定位成功。初始假设错误但通过证据排除并收敛，是有效表现。识别“现有观测不足以区分”也属于正确结论，不强求固定三条观测解决所有问题。

## 5. 每个主题的学习循环

明确问题与前提 → 学习者先画图或复述 → 给出可被推翻的预测 → 查关键源码或做小实验 → 说明证据支持与未证明内容 → 教师给变化场景 → 记录修正与接续点。

- **最小循环**：通常约30分钟，一个问题、一份模型、一个预测、一份证据和一句失效条件。时间为节奏参考，不是强制时限。
- **完整循环**：约90—120分钟，五个必深点按需要加入代码、实验、迁移和反例；可拆成多次会话，不为完成流程拖住所有课程。
- 每个学习主题开始，花几分钟闭卷重建上次关键部分；普通追问、进度操作无需机械重做。主题结束7—14天后抽查保持情况。
- 数据箭头标源/目的、相关地址空间和字节位置；控制箭头标请求、接收者与确认条件；网络图标进程、命名空间、接口与IP/端口。不能强迫所有箭头都标GVA/GPA/HVA/HPA。
- 预测写清改变的条件、预期观察、理由及推翻条件。性能题再加数值方向、量级和统计口径；功能题不强行编数字或“10倍偏差”。
- 关键源码证据应能定位版本及file:line；实验保留实际命令与输出。官方接口语义可用权威文档补充。每份证据说明“排除了什么、没排除什么”。
- 不要求每次必须预测错误。有错记录错在哪里、为何错；预测正确也检查理由、反例与未验证边界。

### AI与学习者的分工

| 环节 | AI负责帮助 | 学习者负责 |
|---|---|---|
| 找入口 | 定位调用链、解释语法与术语 | 确定具体问题与前提 |
| 建模型 | 检查遗漏角色、边界与箭头语义 | 先表达自己的模型 |
| 验证 | 提供实验规格、源码入口、反例 | 先预测，亲自检查证据并解释结果 |
| 复习 | 出变化场景并精确反馈 | 脱离材料推理，说明理由并修正 |

迁移题由教师出，避免仅由学习者选择熟悉条件。需要前置知识或用户直接询问机制时应讲清，不以“不给答案”为由持续猜谜。代码练习优先给规格与分步反馈，不默认代写完整程序；用户当轮明确要求代码时遵从其要求。保留主动阅读关键源码的环节，不要求逐行啃整个仓库。

材料暂不继续扩张，优先使用已有课件与笔记。新材料须有用户新要求或明确教学必要性；生成材料不计理解证据，也不以凑满“三个数字”作为产物指标。

## 6. 最终验收与达标条件

| 形式 | 范围 | 检查重点 |
|---|---|---|
| 闭卷机制与变化题 | 七域各抽一个场景 | 覆盖、因果、迁移 |
| 源码或实验任务 | 至少两个不同领域，其中一个为网络/envd或创建启动 | 独立取证、操作验证、解释结果 |
| 陌生故障案例 | 至少三个，覆盖不同链路 | 提问、假设、观测选择与修正 |

至少一次保持性评估安排在相关主题学习结束7—14天后。基本结构与因果先闭卷；接口细节允许查阅并记录查阅范围。本地简化实验、真实microVM实验、用户实测、教师代跑、纸面推演分别标注；教师代跑只能作为提供的证据，不能计作用户独立操作。

本轮达标需同时满足：

- 七域均完成评估，无尚未触及的领域；关键缺口有补强与复核结果。
- 五项能力在多次任务中稳定达到3分水平，不用单道熟题代替整体判断。
- 网络/envd与创建启动的薄弱链路获得独立解释证据，并至少完成一次相关验证任务。
- 延迟测试仍能重建主要机制，细节遗漏后可自行查证补齐。
- 能主动区分事实、假设与待验证项，不把局部成功当整条链成功。

## 7. 记录格式与接手要求

教师每次有实质教学或新回答后，在学习记录中简记以下信息；不把普通问答都变成完整考试。

```text
日期 / 主题 / 涉及领域：
问题、前提与任务类型：
学习者原始模型与预测：
是否提示、允许查阅内容：
证据：版本+file:line / 实际命令输出 / 纸面推演；由谁执行：
支持与排除的解释 / 尚未排除的解释：
预测偏差与原因，或正确预测的边界：
迁移表现 / 能力分及具体理由（未测项写待评估）：
下次接续与延迟复核安排：
```

其他agent接手时先读AGENTS.md、本文和最新学习记录。沿用同一课序、评分尺度和证据要求，不重新判定用户全部掌握，不把教师示范变为用户成绩。未经用户要求不自动提交推送。

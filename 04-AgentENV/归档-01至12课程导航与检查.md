## 三条复习主线

```text
执行：server 控制对象 → Firecracker / KVM → vCPU 运行 Guest

控制：节点 API → orchestrator → backend → Firecracker API
命令：server → Guest envd → Guest 进程 → 输出与退出事件

存储：Guest 文件系统 → VirtIO → Firecracker → Host ublk
      → daemon / OverlayBD → 层数据后端
```

不是所有操作都经过这几条图的全部节点：缓存命中、不同后端及具体配置会改变路径。旧的 [01—09 复习图示](复习-01至09图示.md) 继续作为辅助，以各课本次校正后的文字为准。

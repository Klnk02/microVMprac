# 第 9 课：命令执行与事件流

2026-10-28。基线：`9f62cbe07cebfecf416dc9bdcf497e2a97687644`。

本轮核对宿主侧 [process.rs](https://github.com/kvcache-ai/AgentENV/blob/9f62cbe07cebfecf416dc9bdcf497e2a97687644/src/sandbox/process.rs)，未追踪 Guest 服务端创建进程的完整实现。

`Executor::start_process_inner` 把 cmd、args、envs、cwd 等打包为 StartRequest，经 envd 的 gRPC process client 调用 start，获取响应流。读取 Start 事件得到 PID 后，返回 ProcessHandle；这不是命令执行结束。PID 用于后续向 envd 选择 Guest 内的进程，不能直接当宿主 PID 使用。

`ProcessHandle::wait` 消费事件流：Data 事件收集 stdout/stderr 并可回调；End 事件提供 exit_code 并形成 ProcessOutput。流中断而未收到 End 会返回错误，不当作执行成功。wait 返回 Ok 与 exit_code 为零是两个判断。

课堂命令使用 python 与参数 hello.py 分开传入，不假设任意命令字符串自动经 shell 解析。Start→Data→End 是基础示意，不承诺每个进程都有输出或只有一条 Data。

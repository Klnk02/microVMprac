每个方块会给出：归属（谁拥有）、共享性（多实例同一份还是各自一份）、读写、数据单位、失效/回收条件。
已核验的模型（2026-11-16，固定提交 + FC 1.12.1）：
同一快照模板的多个沙箱共享同一个只读 ublk 设备（src/sandbox/ublk/device.rs:573-582 注释原文：“share a single ublk device … the same Linux page cache”） → 因此共享该设备在宿主内核里的页缓存页（file-backed、只读）
→ Firecracker 用 MAP_PRIVATE 映射这块后端（firecracker/src/vmm/src/vstate/memory.rs:136） → 某个沙箱写这一页时才 COW 出私有匿名页，私有页不回写设备。
别再把两件事混起来：「只读」讲的是能不能写；mmap 的 flags 讲的是共享还是 COW。 读同一页的两个实例可能命中同一块物理页；写完之后各自持有私有副本。

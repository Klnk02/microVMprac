内存镜像为什么是“只读块设备”

一句话：4 GiB 的内存快照被做成一盘只读光盘，Guest 的 RAM 只是这张盘的投影。碰到没读过的页，内核就去盘上取那一块。
左边是 Guest 看到的页（格子），中间是内核视角的 ublk 设备，右边是用户态 daemon 与层叠存储。
GUEST 视角：这只是“我的 4 GiB 内存”
灰 = 还没驻留在宿主 RAM 里
宿主内核：页表 + ublk 设备
宿主页表项：未建立
缺页 → do_page_fault
/dev/ublkb0 (只读)
内核不懂文件格式，只负责“第几块、多长”
宿主用户态：daemon + 层叠存储
ublk-daemon（收 io_uring 请求）
OverlayBD 索引：逻辑块 → 哪一层
私有可写层（COW 写这里）
只读增量层
只读基层（快照时的内存镜像）
远端 / 本地缓存（可选）
同一份只读基层可被多台实例共享
诚实边界：ublk 是“内核把块请求交给用户态 daemon”的框架，这部分有官方文档支撑； “VMM 具体怎么把这块设备变成 Guest RAM 的映射”（mmap 设备 / userfaultfd / 其它）我没有核对固定提交的实现，属机制级解释。
